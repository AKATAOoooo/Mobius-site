时间线互转

它解决什么问题

跨软件搬时间线，最容易丢的就是层级、转场和变速。这几件事是专门做过的。

嵌套与多轨

解嵌套不丢层级

复合片段、连接片段、多轨叠放按真实时间重叠还原；上层的级联关系会整体上移，不会把同一条轨压在一起。

变速

变速片段不跑偏

按素材最后一帧取端点，陡跳的变速曲线不再让片段尾部出一段斜杠；倒放会提示你导入后勾选。

音频

音频对得上位置

容器里的音频、禁用的音频、L/R 立体声都按原生时间线还原，同一条轨不会出现两段声音互相压住。

交付

转换完先自检

每次转换结束都会检查同轨重叠和变速越界，有问题直接把片段和时间码列出来，导入前就能处理。

安装

下载 DMG，拖进「应用程序」即可，不需要装 Python 或任何依赖。

打开 DMG

双击下载的 Mobius-latest.dmg。

拖进「应用程序」

把 Möbius 拖到右边的 Applications 文件夹。

第一次右键打开

没有 Apple 开发者签名，系统会拦一次：在「应用程序」里右键 Möbius → 打开 → 再点一次「打开」。之后就正常双击了。

常见问题

支持 Intel 芯片的 Mac 吗？

暂时不支持，当前版本只编译了 Apple 芯片（M1–M4）。需要的话可以另外出通用版。

会联网吗？会上传我的素材吗？

不会。全部转换在本机完成，不联网、不上传；只读写你选择的 XML 和输出目录，不改源素材。

倒放片段为什么不自动还原方向？

Premiere 的 XML 里没有可靠的倒放表达，实测多种写法都会被它判成失效。所以画面区间和速度会自动还原，方向需要导入后在 Premiere 里手动勾选「倒放速度」，转换结束时日志会列出是哪几条。

导入 Premiere 后看不到变化？

Premiere 会复用同名素材和旧序列。请新建项目再导入 XML，否则看起来像「没生效」。
